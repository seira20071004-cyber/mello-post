# 「いまと未来」：暮らしの変化を大きく見せる確認版

2026-10-27、ユーザーの「もう少し差がほしい。家の中だけでなく、人・車・休日も使ってよい」という追加指示を反映しました。以前の人物なし・室内だけの方向は固定しません。公開はしていません。

## 何を変えて見せる？

各ペアで、主役になる２〜３個の大きな変化を作ります。小物を一つ入れ替えるだけで終わらせず、家族の人数・年齢・行動、車のサイズや使い方、チャイルドシート、荷物の量、休日の目的や過ごすペースなどを組み合わせます。

例は「家族と荷物でいっぱいの大きな車で慌ただしく出発する今」と「夫婦がコンパクトな車と少ない荷物で身軽に出かける未来」。公園、海辺、旅行の支度、外での食事なども使います。入力が室内や人物なしを指定していれば、それを尊重します。

## 上下をつなぐルール

- 同じ場所・視点を基本に、大きな木、道、家、ベンチ等の目印を残します。
- 車の買い替えも描けます。車種や大きさを同一に固定せず、同じ駐車場所や背景で比較できるようにします。
- 人物は場面に合えば描き、現在の大人は選択した年代、未来は年の差だけ自然に成長させます。人物を毎ページに入れる必要はありません。
- 一投稿は同じ家族の一貫した暮らしとしてつなぎ、未来にも楽しみや温かさを残します。子どもの自立を死別や悲劇として扱いません。
- 英語の画像指示は１時点・１場面だけ。上下分割はプログラムが行い、AI画像の中にさらに２場面を描かせません。
- 年表示はプログラムで合成し、説明文は原則空欄。画像の差で伝えます。

## 確認・保存

未来の生成には現在の画像を参考として渡します。AI点検でも現在と未来の両方を見せ、年代に応じた成長、暮らし方の差、不必要な分割を確認します。人物の存在そのものは問題扱いしません。

画角の完全一致や人物の形・年代は保証できないため、生成後は上下を見比べてください。意味のある差が弱い場合や、形・画風に問題がある場合は点検のメモを表示し、勝手に追加の有料生成はしません。

６ページなら画像は現在・未来の計12枚。片方の失敗では完成した画像を残し、欠けている側だけ再試行します。保存形式は維持しているため、以前の部屋・小物だけの下書きもそのまま編集・出力できます。保存済みの画像は自動で書き換えません。

ことばカードは承認済みの `2c7f049` を基準に維持しています。この変更で、その文章・サンプル・描画・背景の処理は変更していません。

## 検証結果

テスト149件・型チェック・ビルドが成功。実APIで休日の６場面の構成と、現在・未来の車の比較１組を確認しました。車内の配置と、未来にも同じ大型車が残る試作を見て指示を調整し、最終の１組は家族４人と多い荷物・大きな車から、夫婦２人と少ない荷物・小さい車へ変化。1080×1350のPNGに合成して目視確認しています。全６ページの画像を実生成したわけではありません。確認画像はワークスペースの `outputs/いまと未来_暮らしの変化/休日の車の比較.png` にあります。
