# ことばカード：AIへの指示と投稿の流れ

2026-10-27の確認版。公開前のdevelopに反映しています。

## 「具体的に」の指示はどうなっている？

前の版では「表紙以外をすべて２行、各行24文字以内。抽象語だけで終えず、何をするか分かる動作を書く」としていました。そのため、一つ一つの行動を並べる方向に寄り、最後まで対句が続く形でした。

今回からは、**投稿全体で伝える一つの主張を先に決め、その主張に向かって言い換えを重ねる**指示にしています。動作の手順だけに狭めず、親がつい優先することと、同じ場面で大切にしたい行動・見方を対応させます。「心を満たす」だけでは何を意味するか分かりにくいので、見る・聞く対象や、実際にかける言葉を必要な所で残します。

参考投稿の固有の文章・キャラクター・署名は複製せず、入力テーマからオリジナルの文章と背景を作ります。

## ページごとの役割

| 場所 | AIへの指示 | 見せ方 |
| --- | --- | --- |
| １枚目 | 内容に合う28文字以内の短いフック | 本文より大きな太字。長さに合わせて収まる大きさへ調整 |
| ２枚目〜最後から３枚目 | 「やりがちな失敗・つい優先すること より、／同じ場面での、よりよい行動・見方。」。各行24文字以内の２行 | 共通背景に、意味の対応する一対の言葉 |
| 最後から２枚目 | それまでの内容の共通点を、親が抱きがちな後悔・切なさ・不安としてまとめる | 対句から離れ、意味の切れ目で２行、短い本音の言葉へ |
| 最後 | 直前のマイナスに直接答える、希望のある言葉 | 別に生成した結び専用背景に、中央寄せの短い２行（全文40文字以内） |

６枚なら「表紙１枚・対句３枚・振り返り１枚・希望の結び１枚」です。この役割を残すため、新しく作ることばカードは４〜10枚です。

## 感情のつながりで確認すること

- 途中の言い換えが、無関係な育児のコツの羅列になっていないか。
- 「ついしてしまうこと」と「大切にしたいこと」が同じ場面の選択になっているか。
- 最後から２枚目に、それまでにない悩みを急に持ち込んでいないか。
- 最後の言葉が、その後悔や不安に答えているか。「大丈夫」「明日も頑張ろう」だけで済ませていないか。
- マイナスの気持ちは扱うが、親失格・手遅れ等と責めたり、恐怖や絶望を加えたりしていないか。

AIが生成した後、もう一度全体を読ませて校正します。意味のつながりを完全に保証できるものではないので、投稿前に文章を通して確認してください。

## 背景・保存・校正

表紙〜最後から２枚目は共通背景１枚、最後は別の背景１枚です。最後の背景は、同じ色の系統で少し明るくし、紙や布の縁取りと無地の明るい領域を設ける指示です。文字や署名をAIの絵に描かせず、日本語はプログラムが合成します。

文章の生成・編集だけでは画像を生成しません。画像生成ボタンを押した場合だけAPIを呼びます。片方が失敗しても、完成した背景は残し、未生成の背景だけを再試行できます。文字設定の共有では最後の背景を上書きしません。

以前の下書きはそのまま編集・出力できます。以前のことばカードをAI校正で新しい流れに整えた場合、表紙の文章と共通背景は保持し、最後だけ新しい背景を生成できる未生成状態にします。以前の３枚構成はそのまま使えますが、新しい流れへのAI校正には４枚以上の構成が必要です。

本文までと結びの２つの背景が必要なので、新規画像の生成は計２枚です。すでに背景がある側は再利用し、文字の変更だけでは再生成しません。
