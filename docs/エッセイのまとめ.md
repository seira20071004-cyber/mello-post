# 思いを綴る：７枚のおすすめと最後のまとめ

2026-10-27の依頼。「思いを馳せるモード」は現在の表示名「思いを綴る」（essay）として反映。

新しくこのモードへ切り替えると７枚を選び、枚数欄にも「７枚（おすすめ）」を表示する。７枚の構成は表紙１枚・本文５枚・まとめとフォロー案内１枚。枚数は利用者が変更できる。すでに選んだ同じモードを押してもカスタム枚数をリセットしない。他モードのおすすめは６枚のまま。サンプルを開くときも実際の枚数から投稿と画像枠を作る。

最後のまとめは指定枚数に含め、８枚目を勝手に追加しない。ここまでの中心となる思いを短く言葉にし、結局何を伝えたかったかをはっきりさせる。新しい話題へ飛ばず、本文の柔らかさを残す。同じ最終本文へ、空行で分けて次も読むメリットと短いフォロー案内を添える。専用の広告帯を追加せず、既存の本文・字体・位置の編集をそのまま使う。

生成・校正・最後のスライドの再生成に共通の方針を渡す。生成時には最後がsummaryであること、本文がフォロー案内だけでなくまとめを含むこと、同じ本文にフォロー案内があることを検証する。通常の生成の校正・有界な追加修正を使い、API工程を増やさない。背景は従来どおり１枚を全ページで共有する。

既存の６枚の保存済み投稿はそのまま開く・編集・書き出しができ、枚数を自動的に増やさない。新しいルールの検証は明示的なAI生成・校正時に適用する。保存形式・データ移行は変えない。７枚の初期値は新規のモード選択に適用し、保存済みの明示的な枚数は尊重する。

操作サンプルはこれまでの表紙と本文を残し、７枚目に「急いで答えを出さず、自分の気持ちを否定しない」という主旨のまとめと案内を加えた。チュートリアルの枚数説明もこのモードだけ７枚にする。

開発版だけに反映。mainと公開サイトは、確認版への明示的な公開承認後に更新する。
