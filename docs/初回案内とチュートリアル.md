# 初回案内と無料チュートリアル（確認版）

公開側のAPI設定はv1.1.0で反映済み。公開環境の設定リビジョン2にAPIキーと利用パスワードが存在することを再確認した。今回のUX変更ではAPIキーや公開設定、生成ロジックは変更しない。

## 利用者の流れ

- パスワード認証後にスタジオが表示された時点で、そのブラウザではじめての案内を開く。何を作れるアプリか、投稿画像とキャプションが得られることを説明する。
- 「無料で操作を試す」から、テーマとモードを選ぶ→文章を直す→PNG画像を保存する、の３段階を練習できる。
- 用意したサンプルだけを使用し、練習からAIを呼び出さない。本番のAI生成はAPI利用料がかかることを区別して案内する。
- ６モードを選べる。「いまと未来」は画像に添える説明を編集する。情報モードの練習も子育ての例を使用する。
- スキップ、途中で閉じる、Escapeで終了できる。終了をブラウザに記憶し、次回は自動で繰り返さない。保存制限があっても案内自体は利用できる。
- 入力画面の「はじめての使い方」と、既存の使い方ガイド内の「無料チュートリアルをはじめる」から、いつでも開き直せる。

## 下書きを守る仕組み

練習用の入力・本文・画像設定は専用コンポーネントの状態だけに保持する。マイスタジオの作成・更新・アーカイブ処理は呼び出さない。既存サンプルは複製して編集し、元のサンプルや本番の入力を変更しない。案内を閉じたら元の画面に戻る。ブラウザに追加するのは案内の終了フラグのみで、既存の保存形式は変更しない。

## 確認結果

- 162件の自動テスト、型チェック、Next.jsビルド。
- 初回の説明、スキップ、再読み込み後の非表示、入力画面と使い方ガイドからの再表示、Escapeでの終了をブラウザで確認。
- ６モードの練習を開き、編集欄とプレビューにエラーがないことを確認。
- 情報モードと「いまと未来」の文章を変更し、1080×1350のPNGを実際にダウンロード。比較画像の説明に編集内容が反映されることも目視確認。
- 練習前後でマイスタジオ12件を維持。本番の入力は変更なし。API呼び出しは文章0・画像0・点検0のまま。
- 幅390px・高さ680pxのフレームで、説明→編集→完了までを操作。狭い画面でも戻る・進むボタンにアクセスできることを確認。実機のソフトウェアキーボードは未検証。

このチュートリアルはローカル確認版のみ。公開中のv1.1.0へは、利用者がこのUX変更を確認して公開を承認した後に反映する。
