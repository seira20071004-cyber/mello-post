# 初回案内と実画面のチュートリアル

開発ブランチで確認する改善。今回のUXは公開承認前のため、本番サイト・mainには反映しない。

## 初回案内

利用パスワードを通過した後に、mellōの目的を説明する。説明中の「１枚ずつ保存できる投稿画像」の項目は削除。AIで生成した背景にmellōで文字を載せた実際の作例を、物語１・物語２の切り替えで表示する。作例は既存の確認済み創作投稿から取得した `public/examples/` のPNGであり、開くだけで新しいAPI呼び出しは発生しない。

「無料のチュートリアル」は案内そのものが無料という意味。実際のAI文章・画像生成では通常どおりAPI利用料が発生することを、初回説明・進行バー・生成直前で案内する。

## 実際の投稿で学ぶ流れ

別の練習フォームは使わない。編集中の投稿を保存できた場合だけ、新しい通常の投稿を開いて案内を始める。保存に失敗した場合は開始せず、現在の投稿を保持する。

テーマ → モード → 補足 → 届けたい相手 → 枚数 → 人物の年代 → 比率 → 普段の発信内容 → デザイン → 色 → 文体 → 参考画像 → 品質を一項目ずつ説明する。「いまと未来」だけ現在・未来の年を枚数の次に追加する。任意項目は空欄でも進める。

説明は対象の実入力欄のすぐ上に表示し、対象を枠で示す。折りたたんだ任意設定は、その項目の案内時に開く。案内のボタンはフォーム送信しない。

実際の文章生成ボタンを押す → 生成された文章・字体などを編集 → 実際の背景生成ボタンを押す → キャプションを確認 → 実際の「保存へ進む」 → 実際にZIPまたは個別PNGをダウンロード → 「保存してマイスタジオへ」 → 後から編集できることを案内 → 「mellōを活用しよう」で終了。

案内の「次へ」でAPIを呼び出したり、ダミー生成で成功したように見せたりしない。失敗・一部の画像だけ完成した状態では生成案内を保持する。画像の手動アップロードも通常どおり使える。実際のダウンロードに成功してからマイスタジオへの案内へ進む。

## 保存・再表示

案内を途中で終了しても入力・編集・生成済み画像は通常の投稿として残る。投稿の保存先はこのブラウザのマイスタジオで、他端末への同期ではない。案内の進行自体は保存しない。再読み込み後も投稿はマイスタジオから開ける。

初回案内を閉じた記録だけ `mello:welcome:v2` で保存する。以前の練習方式を見た利用者にも新しい方式を一度案内する。LocalStorageが使えない場合も操作は続けられる。既存投稿の保存形式は変更しない。

「はじめての使い方」や使い方ガイドからいつでも再表示できる。案内の終了操作は生成中も使えるが、進行中の生成を中断・再実行する操作ではない。

## 検証

単体テストでは全６モードの手順、必須入力と年の検証、有料操作への自動進行防止、生成成功・失敗・一部画像完了時の画面追従、案内表示記録と既存保存の分離を確認する。既存モード・画像出力・プロジェクト互換性のテストも実行する。
