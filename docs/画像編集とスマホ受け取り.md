# 画像編集とスマホ受け取り（ローカル確認版）

## 変更した操作

- 入力画面からペタル・リーフ・インクのテンプレートとメインカラー選択を削除。仕上げ画面では既存のデザインを変更できる。
- モードの前に、本当に画像生成へ反映される「絵柄」を選択できる。未指定・古い下書きは従来のモードの絵柄。「水彩・ゆる漫画・色鉛筆・パステル」の明示指定だけ画像生成と画像点検へ渡す。
- プレビュー上の文字をクリック／タップして枠を選択。ドラッグ／矢印キーで移動。本文はダブルクリックで枠内編集、または既存の入力欄で編集。物語・言い換え・エッセイに加え、情報モードの項目や比較モードの年・短文にも対応。文字以外のカードや背景は移動しない。
- 丸ゴシック（Zen Maru Gothic）、手書き（Yomogi）、装飾明朝（Kaisei Decol）を追加。PNG生成前に必要な日本語フォントを読み込む。
- 花のモチーフとmellōの名前を使った192／512pxアイコン、180px Appleアイコン、Web Manifestを追加。すでにホーム画面に登録した端末では再登録が必要な場合がある。

## QRの仕組み

送る側の明示操作で、完成したPNGとキャプションだけをサーバーへ送る。編集用データ、APIキー、利用パスワードは受け取りページに渡さない。受け取り用の128bitランダムトークンと、送信・取り消し用の別の128bit秘密値を使う。送信完了前は画像を取得できない。完成後は画像を書き換えられない。

受け取りリンクの有効時間は作成から30分。期限切れの取得は拒否し、その時点で保管物を削除。送る側の「取り消す」も即時削除。ローカルの期限切れ保管物は次のQR作成時にも掃除する。期限そのものと、保管物の物理削除時刻は別。長期間使わなくても物理削除する運用は、公開時にR2のライフサイクル設定を確認して追加する。

PNGは1枚8MB／4000pxまで、最大10枚。作成は認証・同一オリジン確認の後、1時間20回まで（実行インスタンス内）。受け取りトークンはURLフラグメントから読み、API以外へ送らない。APIレスポンスはno-store。QRを知っている人は画像を受け取れるので、QRを公開しない。

スマホでは共有メニューから写真へ保存、または長押し・PNGダウンロードで保存する。写真アプリへの自動保存は行わない。Web Shareが使えない環境では長押しを案内する。端末の写真アプリへの実保存は実機確認が必要。

## ローカル確認

`npm run dev` は同じWi-Fiのスマホから受け取れるよう0.0.0.0にバインドする。生成などの開発用認証は引き続きローカルホストに限定。スマホは公開用受け取りAPIだけを利用する。QRにはそのパソコンのプライベートIPv4を設定する。サーバーは起動したままにする。端末・Wi-Fi・OSファイアウォールの設定によって接続できない場合がある。

ローカル保管先はGit対象外の `.data/transfers/`。フォント・直接編集・QR送信は固定操作サンプルで確認でき、AI呼び出しは不要。

## 公開時の移植

公開前に利用者の確認・承認を得る。Sites／Cloudflareではローカルファイルへの永続保存を使わない。

1. 公開用チェックアウトの作業ブランチでアプリを同期し、必要なnpm依存を追加。
2. `.openai/hosting.json` の `r2` を `BUCKET` に設定（サイトID・既存設定を保持）。これは公開時に初めて実リソースを接続する。
3. `worker/index.ts` のfetch冒頭で `configureHostedTransfers(env)` を呼ぶ。`lib/server/transfer-r2.ts` のアダプタを使い、BUCKETが未接続なら転送は明示エラーにする。
4. このアダプタは `phone-transfers/<token>/` だけを読み書き・削除する。期限切れトークンへのアクセス時に削除。R2ライフサイクルで放置された転送も回収する設定を公開前に確認する。
5. 公開用ビルド、別端末でのQR受け取り、期限・取消・認証を確認してから公開。

## 互換性

既存モードID・保存バージョン2を維持。追加した書体・文字位置・絵柄は同じスキーマに追加し、従来の下書きの既定値を保つ。転送物はマイスタジオのバックアップではない。旧アプリへロールバックすると、新しいフォント名は読み込めないため、その版で新規作成した下書きは事前にPNGへ保存するか、標準書体へ戻しておく。

### ダブルクリックでの枠内編集

- 1回クリックは選択、ダブルクリックは枠内の直接入力。別のポップアップは出さない。Enter／F2でも編集を開始できる。
- 変更は既存の文章欄と保存データに即反映。余白クリック・入力欄からのフォーカス移動・Escape・Ctrl/Command+Enterで編集を終了。通常のEnterは改行。日本語変換中のキー操作では終了しない。
- 文字列が空になっても入力欄を維持し、消して書き直せる。年の編集は従来と同じ4桁・範囲チェックを維持する。
- 固定サンプルの縦書きでダブルクリック→全消去→再入力→右の本文欄への同期→余白で終了を確認。型チェック・関連テスト・最適化ビルド成功。実機タッチのダブルタップとIME実入力は未検証。公開は未実施。
