# 追加３モードの確認版（未公開）

2026-10-27の依頼に基づくdevelopの変更です。main、v1.0.0、公開サイトは更新していません。

## 参考投稿から取り入れたこと

参考投稿の文章や固有キャラクターを複製せず、以下の構成を使って入力テーマに合うオリジナルを作ります。

| モード | 文章と見せ方 | 背景生成の枚数 |
| --- | --- | --- |
| ゆる漫画 | 短い日常場面をつなぎ、最後に気づきへ。中面は縦書き、下半分に丸い線画の人物 | ページごとに１枚 |
| いまと未来 | 同じ場所・画角の現在と想像の未来を上下に表示。年はプログラムで合成 | ページごとに２枚 |
| ことばカード | 表紙以外は「〜〜するより、／〇〇する。」の２行。具体的な行動を対にし、余白のある同じ背景を共有 | 全ページで１枚 |

「いまと未来」は現在の絵を参考画像として未来を生成します。完全に同じ画角になる保証はないため、生成後に比較してください。未来は予測ではなく創作です。人物が出る場合は年の差に応じて年齢も進めます。

## 試し方

1. このパソコンで http://127.0.0.1:3000 を開きます。
2. 追加したモードを選び、「操作サンプル」で無料の文章・配置・編集を試せます。サンプルの背景は配置確認用の仮表示です。
3. テーマを入力してAIで構成を作り、文章を確認してから、明示的な画像生成ボタンを押します。文章の編集だけでは画像生成しません。
4. 「ゆる漫画」は文字の縦横・字体・色・透明度・位置を、「ことばカード」は背景の共有と短文を確認します。
5. 「いまと未来」は現在→未来の順で生成します。片方だけの再生成、手持ち画像への差し替え、年表示と任意の短い説明の編集ができます。失敗時は完成した片方を残し、欠けている画像だけを再試行します。
6. PNG・ZIPで各ページが独立した画像になることを確認します。

６ページの場合、背景の新規生成は漫画６枚、比較12枚、ことばカード１枚です。再生成には別途API利用料が発生します。年・文字の編集と画像アップロードは無料です。年表示を変えても画像内の人物や小物は自動で描き直しません。

ことばカードは２枚目から最後まで各行24文字以内とし、抽象語だけの結びを避けて、その場でできる行動を書きます。AI校正では承認済みの表紙と背景の指示を保持します。以前の自由な文章の下書きも、編集・保存・出力を続けられます。新しい型は新規生成とAI校正に適用します。

## 保存と公開

既存３モード、新規投稿の初期値、以前の下書きを読む処理を維持しています。追加モードの下書きには比較ペアや縦書きなどの情報を保存します。**v1.0.0は追加モードの下書きを編集できません。** コードを旧版へ戻す場合は、新しい下書きが旧版でも扱えると考えず、必要な出力を先に保存してください。

ローカル確認版と公開版では、ブラウザ内の下書き保存場所が別です。GitHubは下書き画像のバックアップではありません。

確認後、ユーザーから公開の承認を受けてからmainへの取り込みと公開版への反映を行います。

## この確認版で検証したこと

- 自動テスト143件、型チェック、Next.jsビルドが成功。
- 新３モードの文章生成を実APIで確認。比較は校正後に、現在30代・20年後50代の整合も確認。

確認用の実画像はワークスペースの `outputs/追加3モード_確認画像/` に保存しています。すべてのページの背景を実生成したわけではありません。AI画像の人物・画角・余白は生成ごとに変わるため、投稿前の目視確認が必要です。
